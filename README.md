Unity tic-tac-toe example using the minimax algorithm.

## Getting started

- Clone the repository and add `.` to Unity Hub as an existing project.

- Use the recorded Editor version as the starting point. For an upgrade, work on a separate branch and preserve all `.meta` files and serialized asset references.

- Open a project scene in the Editor and enter Play mode. Available scene examples: [Assets/Scenes/TicTacToe.unity](https://github.com/kleberandrade/tic-tac-toe-minimax-unity/blob/master/Assets/Scenes/TicTacToe.unity).

## Recorded requirements

- Recorded Unity Editor: **2019.4.0f1** in [ProjectSettings/ProjectVersion.txt](https://github.com/kleberandrade/tic-tac-toe-minimax-unity/blob/master/ProjectSettings/ProjectVersion.txt).
